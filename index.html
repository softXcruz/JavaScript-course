Strings Text

Un String es un tipo de dato primitivo utilizado para representar y manipular secuencias de texto. Son inmutables; cualquier transformación genera una nueva cadena en memoria.

Métodos Clave Referencia

  • .length: Longitud de cadena.
  • .toUpperCase(): Mayúsculas.
  • .includes(): Búsqueda.
  • .trim(): Elimina espacios en blanco.
  • .slice(inicio, fin): Extrae una parte de la cadena.
  • .replace(buscar, nuevo): Reemplaza una subcadena por otra.
  • .charAt(index) / [index]: Retorna el carácter en la posición dada.
  • .startsWith() / .endsWith(): Comprueba el inicio o fin del texto.
  • .indexOf(sub): Retorna el primer índice donde encuentra el texto.

Numbers

En JavaScript, los números se representan como tipo Number (formato flotante de 64 bits IEEE 754). Maneja tanto enteros como decimales bajo el mismo tipo de dato, e incluye valores especiales como NaN e Infinity.

Métodos Clave Referencia

  • Number.parseInt(): Convierte un string a un número entero.
  • Number.parseFloat(): Convierte un string a número decimal.
  • .toFixed(digits): Formatea un número especificando decimales.
  • Number.isInteger(): Determina si el valor pasado es un entero.
  • Number.isNaN(): Evalúa si el valor es NaN.
  • Math.round() / .floor() / .ceil(): Redondeo estándar, hacia abajo o hacia arriba.
  • Math.random(): Genera un número pseudoaleatorio entre 0 y 1.
  • Math.max() / Math.min(): Devuelve el valor más grande o más pequeño.
  • Math.abs(): Retorna el valor absoluto de un número.

Operators

Los Operadores son símbolos o palabras clave especiales que permiten manipular valores y variables en JavaScript. Se clasifican en Aritméticos, Asignación, Comparación, Lógicos y el operador de encadenamiento opcional (?.) o de fusión nula (??).

Operadores Clave Referencia

  • + - * / % **: Aritméticos (Suma, resta, mult, div, módulo, potencia).
  • === vs ==: Igualdad estricta (compara tipo y valor) vs débil (coerción).
  • !== vs !=: Desigualdad estricta vs débil.
  • && || !: Operadores Lógicos (AND, OR, NOT).
  • condicion ? a : b: Operador Ternario (Sintaxis corta de if/else).
  • += -= *= /=: Operadores de Asignación compuesta.
  • ??: Nullish Coalescing (Retorna el operando derecho si es null o undefined).
  • ?.: Optional Chaining (Acceso seguro a propiedades sin lanzar error).

Booleans

Un Boolean representa un valor lógico que solo puede ser true o false. Son la base del control de flujo en JavaScript. Los valores en JS también se evalúan como Truthy o Falsy según el contexto condicional.

Conceptos Clave Referencia

  • true / false: Los dos únicos literales booleanos primitivos.
  • Boolean(val): Función global que convierte cualquier valor a booleano.
  • !!val (Doble NOT): Forma idiomática rápida para castear un valor a booleano.
  • Valores Falsy: false, 0, "", null, undefined, NaN.
  • Valores Truthy: Todo lo que no sea Falsy (ej: "0", [], {}, números neg/pos).
  • ! (NOT lógico): Invierte el valor de verdad de una expresión.

Objects

Un Objeto es una estructura de datos fundamental en JavaScript que almacena colecciones de pares clave-valor. A diferencia de los tipos primitivos, los objetos son estructuras de datos compuestas y mutables que se pasan por referencia en memoria.

Métodos y Conceptos Clave Referencia

  • Object.keys(obj): Retorna un arreglo con las llaves del objeto.
  • Object.values(obj): Retorna un arreglo con los valores del objeto.
  • Object.entries(obj): Retorna pares [clave, valor] en arreglos.
  • Object.assign(target, src): Copia propiedades de uno o más objetos.
  • { ...obj } (Spread): Clona superficialmente un objeto.
  • Destructuring: Extrae propiedades directamente en variables (const { name } = obj).
  • Object.freeze(obj): Congela un objeto impidiendo modificaciones.
  • Object.seal(obj): Previene añadir/eliminar propiedades, pero permite editar existentes.
  • hasOwnProperty(key): Verifica si posee una propiedad propia.

Arrays

Un Array (arreglo) es una estructura de datos tipo lista utilizada para almacenar múltiples elementos en una sola variable. Los arreglos en JavaScript son redimensionables, pueden contener datos de diferentes tipos y están indexados a partir de cero (0).

Métodos y Conceptos Clave Referencia

  • .push() / .pop(): Añade o elimina un elemento al final del arreglo.
  • .unshift() / .shift(): Añade o elimina un elemento al inicio.
  • .length: Propiedad que indica la cantidad de elementos.
  • .includes(val): Verifica si un elemento existe en el arreglo.
  • .indexOf(val): Retorna el primer índice del elemento o -1.
  • .slice(start, end): Copia una porción del arreglo sin modificar el original.
  • .splice(start, deleteCount): Añade, elimina o modifica elementos in-place.
  • .concat() / [ ...arr ]: Combina o clona arreglos de forma limpia.
  • .join(sep): Convierte un arreglo en un string uniendo sus elementos.

Functions

Las Funciones son bloques de código reutilizables diseñados para realizar tareas específicas. En JavaScript, las funciones son ciudadanos de primera clase (*first-class citizens*), lo que significa que pueden asignarse a variables, pasarse como argumentos y retornar de otras funciones.

Conceptos Clave Referencia

  • Function Declaration: Definición tradicional con soporte de *hoisting* (function miFuncion() {}).
  • Function Expression: Asignación de función a variable (const fn = function() {}).
  • Arrow Functions () => {}: Sintaxis compacta sin su propio contexto de this.
  • Parámetros por Defecto: Asigna valores iniciales (function saludar(nombre = "Invitado")).
  • Rest Parameters (...args): Permite agrupar un número indeterminado de argumentos en un arreglo.
  • Callbacks: Funciones pasadas como argumentos a otras funciones para ejecutarse después.
  • Closures: Capacidad de una función interna de acceder al ámbito de su función padre.
  • IIFE: Funciones ejecutadas inmediatamente al definirse ((function() {})()).

Iterators & Loops

Los Iteradores y Bucles permiten repetir bloques de código o recorrer estructuras de datos (como arrays, strings u objetos) de manera eficiente. JavaScript ofrece múltiples mecanismos desde el clásico bucle for hasta iteradores modernos.

Conceptos Clave Referencia

  • for (let i = 0; ...): Bucle tradicional basado en contador e índice numérico.
  • for...of: Itera directamente sobre los valores de objetos iterables (Arrays, Strings).
  • for...in: Itera sobre las llaves (*keys*) enumerables de un objeto.
  • .forEach(): Método de arrays para ejecutar una función por cada elemento.
  • while / do...while: Bucles condicionales que se ejecutan mientras una expresión sea verdadera.
  • break & continue: Control de flujo para salir de un bucle o saltar a la siguiente iteración.

Array Methods (Avanzados)

Los Métodos de Orden Superior en arreglos permiten transformar, filtrar y reducir datos de manera declarativa y limpia, siguiendo los principios de la programación funcional sin mutar directamente los datos originales en la mayoría de los casos.

Métodos Clave Referencia

  • .map(): Transforma cada elemento y retorna un nuevo arreglo con la misma longitud.
  • .filter(): Evalúa una condición y retorna un nuevo arreglo con los elementos que pasen el filtro.
  • .reduce(): Acumula los valores del arreglo en un único resultado (número, objeto, etc.).
  • .find(): Retorna el primer elemento que cumpla con la condición especificada.
  • .findIndex(): Retorna el índice del primer elemento que cumpla la condición.
  • .some() / .every(): Comprueban si al menos uno o todos los elementos cumplen una condición.
  • .sort(): Ordena los elementos de un arreglo (¡modifica el arreglo original!).

DOM (Document Object Model)

El DOM es una interfaz de programación que representa la estructura jerárquica de un documento HTML como un árbol de nodos. JavaScript lo utiliza para leer, modificar, añadir o eliminar elementos visuales y estilos en tiempo real de una página web.

Métodos Clave Referencia

  • document.getElementById(): Selecciona un elemento único por su ID.
  • document.querySelector(): Selecciona el primer elemento que coincida con un selector CSS.
  • document.querySelectorAll(): Retorna una lista de nodos con todos los elementos que coincidan.
  • .textContent / .innerHTML: Lee o modifica el contenido de texto o HTML interno.
  • .createElement(): Crea un nuevo elemento HTML en memoria.
  • .appendChild() / .remove(): Inserta o elimina nodos del documento.
  • .addEventListener(): Escucha eventos del usuario (como click, input, etc.).
  • .classList.add/remove/toggle: Manipula clases CSS de forma dinámica.
